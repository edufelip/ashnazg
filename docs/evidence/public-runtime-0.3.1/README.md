# Public runtime distribution acceptance

[Ashnazg v0.3.1](https://github.com/edufelip/ashnazg/releases/tag/v0.3.1) was published by [run 45464686984](https://github.com/edufelip/ashnazg/actions/runs/45464686984). The public tag points to the accepted source `509a74a329529f764f8fef955f45c04eed3e02cc`, prepared by [run 45392351351](https://github.com/edufelip/ashnazg/actions/runs/45392351351) and accepted prepublication in [runtime-release-0.3.1](../runtime-release-0.3.1/README.md). All ten uploaded assets (727,503,760 bytes total, see `anonymous-assets.json`) were downloaded with plain anonymous `curl -fL` (no token, no cookies, no `gh`), pass `shasum -a 256 -c SHA256SUMS`, and match the accepted candidate's SHA-256 values and sizes and GitHub's reported asset digests.

The public macOS ZIP was extracted. Both binaries are ad-hoc signed and verify with `codesign --verify --strict`; `bin/ashnazg-vm` carries only the `com.apple.security.virtualization` entitlement, is byte-identical to the published helper asset, and both binaries link only system libraries (`package-verification.json`). Its `bin/ashnazg mcp` then ran with a different, initially empty private HOME, no manually staged runtime, an empty tool PATH, and no host SDK, external Android serial, or external agent-token variables. The native CLI acquired its catalog-bound runtime from the fixed public release URLs and started the VM. Both cache and state snapshots were empty before this run.

The cold run passed all five tools, inferred fixture installation, `Count: 0` to `Count: 1`, fresh snapshot IDs and changed normalized screenshot pixels. EOF joined CLI/helper/bridge shutdown, removed credentials, closed all three listeners and retained the new persistent disk. The cold run needed six readiness polls ("native runtime is still starting") while the runtime was downloaded and started; the driver's retry counter recorded them and the run was not repeated. After teardown the run waited 30 seconds, then the warm run passed on its first attempt with the same HOME, the same cache identity and the same persistent disk identity.

The warm run launched only the CLI subtree through the retained `sandbox-exec` profile (`host-network-policy.sb`, sha256 `dfc42c68…1347`). Outbound IPv4 and IPv6 probes under that profile returned EPERM (`network-denial.json`); fixed loopback relay ports remain allowed. The controller stays outside because macOS refuses execution of setuid `/bin/ps` inside the sandbox. The retained wrapper records exactly one profile application to the verified CLI command and checks the policy hash before and after the run. This qualifies host artifact-cache reuse with outbound IP denied; guest NAT may use external host services, so whole-guest network isolation is not claimed.

The public package's `platform/ios` sources passed `env -u ASHNAZG_IOS_FIXTURE_SOURCE python3 platform/ios/verify_mcp_fixture.py --binary <public packaged bin>`: it exited zero, the owned work directory was removed and the owned simulator was deleted ([ios-fixture receipt](ios-fixture/receipt.json)).

Driver-observed readiness was 213.163 seconds cold (including the public download) and 30.005 seconds warm. The helper's startup intervals were 114.689 and 31.169 seconds. These are single observations on the recorded macOS host, not a startup distribution or a performance claim. A fresh HOME is not a factory-reset-machine test.

Each run checked retained evidence and runtime diagnostics against its two actual session tokens, held only in memory; no match was found. Retained files cannot independently attest the external environment or those secret values. Screenshot PNGs were decoded and pixel-compared by the driver but are not retained, and `serial.log` is kept gzipped. The binaries remain ad-hoc signed without Developer ID/notarization; intrinsic compiler-to-binary provenance and legal clearance are not claimed.

The [receipt](receipt.json) binds all retained payloads. The [prepublication evidence](../runtime-release-0.3.1/README.md) separately covers EOF, idle SIGTERM and client-observed in-flight SIGTERM for these unchanged release bytes.
