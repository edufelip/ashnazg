# Packaged CLI and VM acceptance

The unchanged candidate from Release prepare [45392351351, attempt 1](https://github.com/edufelip/ashnazg/actions/runs/45392351351) passed all three prepublication modes on Apple Silicon macOS: EOF, idle SIGTERM, and SIGTERM during a client-observed pending long press. Its source is `509a74a329529f764f8fef955f45c04eed3e02cc`. The artifact, catalog, and candidate hashes are bound in [receipt.json](receipt.json). The 726,560,081-byte artifact zip was downloaded from GitHub's artifact API and its SHA-256 matched the API-reported digest `652e2363fda7986a2c9e4dcbdc3919ed6b89a75829bb2dc0037b438b344287f3` before extraction; every `SHA256SUMS` entry and `scripts/runtime_release.py verify --version 0.3.1` then passed. The macOS package carries ad-hoc codesigns, the helper's `com.apple.security.virtualization` entitlement, system-only `otool -L` dependencies, and `platform/ios` sources byte-identical to this commit; the packaged helper matches the catalog's helper artifact hash.

Each run used the packaged `bin/ashnazg mcp` with a private HOME and an explicitly staged, catalog-verified cache created offline by the `stage_runtime_candidate` example; no network acquisition was involved in staging. The driver supplied no host SDK tools, external Android serial, or external agent token. All five tools passed, including inferred fixture installation, `Count: 0` to `Count: 1`, fresh snapshot IDs, and changed normalized screenshot pixels. The screenshots were decoded, dimension-checked and pixel-compared by the driver but are not retained in this directory.

All modes exited with status zero, joined the CLI, observed the helper and bridge gone, removed credentials, closed all three listeners, and preserved captured persistent state/cache identities. `runtime.json` and `serial.log` are rewritten diagnostics; disk contents may change. The in-flight run submitted a long press, observed no response for 209 ms, sent SIGTERM with stdin open, and observed no successful reply. It does not assert a server-entry timestamp.

CLI-observed readiness was 32.065, 32.064, and 28.730 seconds. Helper startup intervals were 31.321, 33.044, and 30.380 seconds, measured as warm VM restarts after initial diagnostic boots. These are different single-run intervals, not a performance distribution or cold-acquisition result.

The executed driver and wrapper are retained unchanged. On this host the packaged helper's guest relay rebind across rapid warm restarts was intermittently unhealthy: several diagnostic boots failed fast at `app_install` (`native APK installation failed`) and one failed outright with `cannot bind 127.0.0.1:7777: Socket is not connected`. Every retained failure is summarized in [flaked-attempts.json](flaked-attempts.json); each accepted mode run passed after a settle delay following the previous teardown (`sigterm-inflight` needed one retry). The failure mode is documented as an observed limitation of this candidate on this host, not as accepted behavior. Each passing run scanned its retained evidence and runtime diagnostics against both actual session tokens held only in memory. No matching secret was found.

The packaged `platform/ios` sources also passed the required fixture verification: `env -u ASHNAZG_IOS_FIXTURE_SOURCE python3 platform/ios/verify_mcp_fixture.py --binary <packaged bin>` exited zero, the owned work directory was removed, and the owned simulator was deleted on close. The retained [ios-fixture receipt](ios-fixture/receipt.json) records the live snapshot, tap, append-proof typing, secure-field redaction, rejected-input boundaries, and the disabled Android tool in iOS mode.

This acceptance does not establish public cold acquisition, network-denied warm reuse, Developer ID signing/notarization, intrinsic compiler-to-binary provenance, or legal clearance. Retained files cannot independently attest the external environment or actual secret values used by the scan. Those publication and acquisition steps remain separate. The helper's ad-hoc signature and virtualization entitlement were verified locally.
