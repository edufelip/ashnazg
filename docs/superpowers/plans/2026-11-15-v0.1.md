# Ashnazg v0.1 Implementation Plan

> For agentic workers: use subagent-driven-development, parallel ownership explicitly requested by the user, followed by orchestrator integration and independent review. Do not start nested agents.

**Goal:** Implement the complete first-milestone Android control layer and make its correctness continuously testable in public GitHub CI.

**Architecture:** Persistent Android UiAutomation instrumentation exchanges bounded authenticated JSON-RPC with a native Rust host. Separate setup (adb) from UI control (persistent RPC). Use public Android APIs and report unsupported future runtime features honestly.

**Tech Stack:** Rust native host, Java 17 Android framework bridge, Gradle/AGP, Python standard-library integration and benchmarks, GitHub Actions.
