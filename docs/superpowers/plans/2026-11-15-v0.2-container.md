# v0.2 Linux Container Backend Implementation Plan

> **For agentic workers:** Use subagent-driven-development, separate owned paths, no nested agents, orchestrator integration and independent review.

**Goal:** Add a real, measured Linux ReDroid backend and reusable GitHub Action while preserving v0.1's existing emulator gate. Track the derived-image and dynamic-VSync portions of the blueprint separately until implemented and verified; do not silently call those complete.

**Architecture:** A bounded Python lifecycle supervisor provisions a digest-pinned upstream Android15 container, exposes ADB only on host loopback, waits for boot/focused drawn application readiness, and runs an explicit user command with ANDROID_SERIAL set. The same integration and benchmark runners provide acceptance evidence. The reusable Action invokes this supervisor with guaranteed owned-resource cleanup. No upstream image is republished in the initial backend pass.

**Tech Stack:** Python standard library, Docker/ReDroid, existing Rust/Java harness, GitHub Actions.

## Contract

`python3 scripts/redroid.py run --output-dir artifacts/redroid [--adb-port 5555] [--timeout 180] -- <command> [args...]`

The command executes only after readiness with an explicit ANDROID_SERIAL. Boot deadline is separate from the command deadline (`--command-timeout`, default2400 seconds; zero explicitly selects a persistent service). Nonzero child status propagates. Signals/timeouts/failures trigger owned cleanup. Runtime/container logs and a JSON receipt go under output-dir, recording source SHA, image index and resolved platform digest, actual host/kernel/arch/runner image, dimensions/settings, setup timings and resource measurements when available. Failure never masquerades as zero measurement. No control input is injected by the lifecycle supervisor.

Default immutable image: `redroid/redroid@sha256:81889852444606824d33eb0232fa5813bce3f0993afe871785120af0d7c991ad`.
Expected manifests: amd64 `sha256:25879821f13ffd38d5d6047d832379b96cf72ec520508b45036dca25cdc3737f`; arm64 `sha256:b21c57533662275928832602f7c09b83cb198aa9b271135ae49d978857d6795f`.
Display:720x1280,dpi320,software renderer,30fps,memfd replacing ashmem. This is a static configuration, not a dynamic VSync governor.
